# חוברת יחס ופרופורציה — כיתה ח׳ · מסמך הוראות

מסמך זה מרכז את **כל חוקי העיצוב, המבנה והעבודה** של חוברת "יחס ופרופורציה" לכיתה ח׳,
כפי שגובשו יחד עם יניב רז. כל עריכה עתידית — אנושית או של סוכן AI — חייבת לפעול לפיו.

> החוברת היא תת־אפליקציה (Vite + React + TypeScript) בתוך פרויקט `razpages`.
> מקור האמת של החוברת: `sources/lovable/ratio-workbook/`.
> המוצר הסופי הוא **דף עבודה A4 להדפסה** — האתר והגלילה הם אמצעי צפייה, ניווט והדפסה בלבד.

---

## 1. מהות ומבנה

- **מהות:** משכפלים בנאמנות חומר מקור לדף עבודה A4 מעוצב. **לא ממציאים** שאלות/תשובות/נתונים
  שאינם במקור. מקור התוכן העיקרי: חוברת "יחס — כיתה ח׳" מאת **ד״ר יחיאל תנעמי ואיילת קריספין**.
- **מקור אמת של הדפים:** `src/data/worksheetPages.tsx` — מערך `WORKSHEET_PAGES` אחד, לפי סדר
  ההופעה בחוברת. כל דף הוא רכיב React. שדה `credit: 'authors' | 'yaniv'` קובע את הקרדיט בתחתית.
- **חלוקה לפרקים:** מושגים בסיסיים · חלוקה ביחס נתון · כתיבה והשוואת יחסים · יחס מצומצם ·
  שמירת היחס · יחס בגאומטריה ובכמויות · פרופורציה · שאלות מיצ״ב · שאלות מתוך תוכנית הלימודים.
  פרק חדש מתחיל בעמוד חדש; הכותרת הכחולה נושאת את שם הפרק בנוסח **"יחס - <שם הפרק>"**.

### דפי "למורה" מול דפי תלמיד
- **דפי הפתיחה למורה** (בלוק הפתיחה, בתחילת החוברת בלבד): כותרת **"יחס · למורה"**, **ללא מספור**,
  ו**מכילים את הפתרונות** וההנחיות של המחברים. קרדיט תחתית: **ד״ר יחיאל תנעמי · איילת קריספין**.
- **דפי מורה שאינם בפתיחה** (באמצע החוברת): מקבלים כותרת פרק רגילה ומספור רגיל, ו**אינם מכילים
  פתרונות פתורים** — הם ריקים לתלמיד (הפתרונות נשמרים רק בבלוק הפתיחה). קרדיט המחברים נשמר.
- **דפי התלמיד:** ממוספרים **החל מ־1** בדף הראשון שאינו דף פתיחה. קרדיט תחתית: **יניב רז -
  מדריך מחוזי חט"ב בעיר ירושלים**.

## 2. חוקי העיצוב (מחייבים ואחידים בכל החוברת)

### תיבות מענה
- **תיבה נקייה אחת לכל סעיף.** אין תווית "דרך" ואין תווית "תשובה" בתוך תיבות התלמיד — התיבה עצמה
  היא מקום המענה. אין קווים פנימיים מיותרים ואין שורת תשובה מיותרת מתחת לתיבה.
- **מסגרת הפאנל:** פינות ישרות; **קו עליון עבה** (סימון "כתוב כאן"), שאר הצלעות דקות. תווית
  משמעותית (נימוק/יחידה/אות סעיף) — אם קיימת — היא **כחול כהה על רקע לבן**, בלי פס מלא ובלי קו מפריד.
- **מקום פתרון לכל סעיף — צמוד לסעיף.** אין תיבה משותפת בתחתית שאוספת את כל התשובות. כל תת־שאלה
  מקבלת את מרחב הפתרון/התשובה שלה מיד אחריה.
- **מבנה התשובה נגזר מהשאלה:** יחס → תיבות `▭ : ▭`; זוג סדור → `( ▭ , ▭ )`; חישוב → תיבת כתיבה;
  זיהוי/סימון → סימון על הדף (בלי תיבה מיותרת). שאלת "הקיפו/בחרו את ההיגדים" מקבלת **תיבת נימוק אחת**.
  שאלת "סמנו את האיור" — בלי מספרי אפשרויות, עם תיבת **"הסבירו את בחירתכם"**.
- **גודל מקום המענה נגזר ממה שצריך לכתוב.** אם אין מקום — מפצלים לדף נוסף; לא מכווצים ולא דוחסים.
- **משבצות השלמה** (למשל `6/□ = 2/3`) גדולות מספיק לכתוב בהן מספר.

### טקסט, מספור וכיוון
- עברית RTL. **מיספור סעיפים אחיד: `א.` `ב.` `ג.`** (לא בסוגריים).
- **טבלאות היגדים נקראות מימין לשמאל:** עמודת ה־#/התווית מימין, ואז הטענה / נכונה / לא נכונה.
- סימן כפל המוצג לתלמיד הוא **נקודה אמצעית `·` בלבד** (לא `×` ולא `x`).
- טקסט/מספר בכיוון LTR בתוך SVG או תיבה מקבל `direction="ltr"` כדי שלא יתהפך (למשל "____°",
  "____ ש״ח", ומספרי צירים בגרפים).

### צבע וגרפיקה
- **כחול כהה אחיד `#1f2a44`** לכל האקצנט: כותרת עליונה, קו הכותרת, עיגול המספר, נקודות תחילת
  שאלה, תוויות סעיף ומסגרות הפאנל.
- **ציורים וגרפים ברורים ומדויקים:** גדולים מספיק שהכיתוב קריא; מדידה מחושבת (לא בעין); אגדת גרף
  מתחת לגרף (בלי חפיפה על העמודות); קווים חדים אך לא כבדים.

### כותרת תחתית
- שתי שורות בכל דף. דפי המחברים: `ד"ר יחיאל תנעמי · איילת קריספין`. שאר הדפים:
  `יניב רז - מדריך מחוזי חט"ב בעיר ירושלים`. שורה שנייה בשני המקרים:
  `הדרכה במחוז ירושלים והעיר ירושלים - מנח"י, בהובלת איילת קריספין`.

## 3. איך זה בנוי ונפרס

- **מקור:** `sources/lovable/ratio-workbook/` (בתוך `razpages`). רכיבי הדפים תחת
  `src/components/worksheet/`; שכבות עיצוב `src/*.css`; נתוני הדפים `src/data/worksheetPages.tsx`.
- **בנייה:** `npm run build` (Vite) מהדר את המקור ל־`dist/`. הכלי `scripts/_build-full-workbook.mjs`
  מרנדר את כל הדפים לקובץ HTML יחיד ועצמאי עם **פריסה אוטומטית ל־A4** (כל שאלה זורמת וממלאת עמוד;
  אין דפים ריקים ואין חיתוך), ומזריק את דפי המורה/תלמיד, המספור והכותרות התחתונות.
- **פרסום:** הקובץ מועתק ל־`index.html` בריפו הציבורי העצמאי **`yanivmizrachiy/ratio-workbook`**
  (ענף `main`, שורש), ו־GitHub Pages מפרסם אוטומטית. הקישור הציבורי:
  **https://yanivmizrachiy.github.io/ratio-workbook/**
- **הפרדה מלאה מפיתגורס:** הפרסום של יחס עצמאי לחלוטין ואינו תלוי ב־CI של `razpages`.

## 4. איך לערוך (זרימת עבודה)

1. עורכים את המקור תחת `sources/lovable/ratio-workbook/src/`.
2. `npm run build` (מהדר) → ואז `node scripts/_build-full-workbook.mjs <out.html>` (בונה את החוברת).
3. **מאמתים במדידה בדפדפן** (לא בעין): 0 גלישה מ־A4, 0 גלישה אופקית, יישור תיבות, כיוון טבלאות,
   קריאוּת גרפים. מתקנים עד שנקי.
4. מעתיקים את ה־HTML ל־`index.html` בריפו הציבורי, `git commit` + `git push` → Pages מתעדכן.
5. **תיקון = לכל הדפים:** כל תיקון עיצובי מוחל באופן אחיד על כל הדפים המתאימים, לא רק על הדף שנצפה.
